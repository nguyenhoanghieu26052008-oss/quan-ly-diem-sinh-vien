# Quản lý điểm sinh viên - Streamlit

## Chạy trên máy
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy Streamlit Community Cloud
1. Đưa `app.py` và `requirements.txt` lên một repository GitHub.
2. Đăng nhập Streamlit Community Cloud.
3. Chọn **Create app**.
4. Chọn repository, branch `main`, file `app.py`.
5. Nhấn **Deploy**.
